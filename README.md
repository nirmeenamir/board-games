# ♟️ GameBoard — Board Games Framework

A modular C++ framework that implements **11 board games** using a template-based generic game engine for type-safe extensibility.

---

## 🎮 Supported Games

| Game | Variant |
|---|---|
| Tic-Tac-Toe | Classic |
| Tic-Tac-Toe | Misère (reverse rules) |
| Tic-Tac-Toe | Diamond |
| Tic-Tac-Toe | Pyramid |
| Tic-Tac-Toe | Numerical |
| Tic-Tac-Toe | Word-based |
| Tic-Tac-Toe | Obstacles |
| + 4 more board games | Various |

## ✨ Features

- ♻️ **Reusable Core** — Generic `Board<T>`, `Player<T>`, `GameManager<T>` components
- 🔌 **Easy to Extend** — Add new games with minimal code duplication
- ✅ **Robust Input Handling** — Validated input with win/draw detection algorithms
- 📄 **Full Documentation** — Comprehensive Doxygen HTML docs

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| C++ | Core framework |
| Template Programming | Generic type-safe game engine |
| Doxygen | Auto-generated HTML documentation |
